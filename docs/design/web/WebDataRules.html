Website · rules for the build
No city, currency or price is ever typed into a page.
Launching city #3 (or country #3) is an admin action in Markets. The website changes by itself.
How we know where you are
  1. Saved address (signed in) or last address (cookie)
  2. Browser location, only after the visitor taps "Use my location"
  3. IP lookup, as a hint only ("Looks like you're near …"), shown only if that place is inside a live zone
  4. Nothing known: first-visit page, no city named
Comes from data
  • Countries, states, cities and status (live / soon), from Markets
  • Counts ("42 kitchens deliver to …", "2 cities live")
  • Currency, number and date format, from the zone's country
  • Kitchens, cuisines, times and delivery fees, from the zone and the rule engine
  • Example bills: a cached real quote for the visitor's zone
  • Offers and who funds them
  • Greeting by local time; name only when signed in
  • Country (header): from address, else IP, else browser locale. It decides currency, kitchens and the language list
  • Language (header, separate from country): English by default; the choices come from the country's locales in Markets (India: English, हिन्दी, తెలుగు, தமிழ், ಕನ್ನಡ, मराठी, বাংলা · United States: English, Español). Remembered per visitor; never changes prices
Pages and states
  • /: first visit, or personal home once an address is set
  • /cities: full directory, country tabs, then states, then cities, plus search
  • /{country}/{city}: city page, generated for every live city (search engines)
  • Address outside every zone: "Not in your area yet" + "Notify me"
  • "Coming soon" cities collect sign-ups (demand data for Markets)
  • Footer never lists cities; it links to /cities
Test that keeps it honest: add a third city in admin Markets (status live, one zone, one kitchen) on a clean database, without changing code. The directory, the city page, the sitemap and the personal home for an address there must all appear. A build check fails if any page template contains a seeded city, state or country name.
